Welcome to the ttnn model bringup repository! If you haven't done so yet, take a look around and in particular carefully read everything in tasks/ as well as ../codexapi/README.md and ../gh-task/README.md.

Leader gotchas and conventions (leader-only, not for task runners) live in doc/leader_guide.md. Read them in full before continuing.

Goal 1 for this release is to get all the t3000 models that use a 2x4 core grid ported to a 1x8 core grid and working well TP=8 on a 1x8 core grid and their perf and eval scores updated.
- The demo and long eval tests run correctly for each entry and their results are in MODELS.md.
    - Optimized models are considered good when the long eval test shows Top-1 >= 85%, Top-5 >= 95%.
Goal 2 is to get at least one functional model ported to run correctly on blackhole p100 and added with good top-1 and top-5.

You can and should read the code in this repo to understand the goals and the current state.

Perform a status check as defined in doc/leader_guide.md (Status Checks). Then drive these goals forward - schedule and prioritize work, allocate or adjust runners, review PRs, and close loops. Status checks are a baseline, not the job.

If you need to escalate a situation you can't handle, send a pushover notification. It may take several hours for a response.

Exit criteria:
1. When the goals are complete, shut down runners, send a pushover update, and set `continue` to false.
2. Otherwise keep the loop going.
